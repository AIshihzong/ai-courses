# 17｜無程式碼自動化、Vibe Coding 與創意 AI

> 適合對象：不會（或不想）寫程式，但想用 AI 自動化工作流程、做出自己的小工具，或用 AI 創作影像、影片、音樂的人。
> 2025–2026 年的重要變化：**「Vibe Coding」**（以自然語言指揮 AI 寫程式）讓非工程師也能做出可用的產品；n8n、Dify、Coze 等工具讓 AI 代理的建置門檻大幅降低。官方免費教學已相當完整，不必急著買高價課程。

## 選課建議

| 你的目標 | 建議 |
|---|---|
| 把重複性行政工作自動化 | n8n 或 Make 官方課程 → 挑一個每週都要做的流程實作 |
| 做出一個自己的小網站／小工具 | Vibe Coding 101 → Easy-Vibe（中文）→ 遇到卡關再補程式基礎（見 [18](18-prerequisites.md)） |
| 在公司內建一個知識庫問答機器人 | Dify 或 Coze 官方教學 → 了解 RAG 概念（見 [05](05-generative-ai-apps.md)） |
| AI 繪圖／影片創作 | Runway Academy 或 ComfyUI 文件 → 社群工作流程 |
| 想更進一步理解原理 | 回到 [01｜AI 通識](01-ai-literacy.md) 與 [學習路線圖](../docs/learning-paths.md) |
