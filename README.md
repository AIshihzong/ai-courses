# AI 課程大全：全網 AI 課程中文整理與分析

> 從全球各大平台、頂尖大學、AI 公司官方學院與中文社群中，篩選約 **100 門 AI 課程與學習資源**，加上 **10 餘項 AI 認證**，全部以**繁體中文**翻譯、介紹與點評，並附上趨勢分析與學習路線圖。

- **資料整理日期**：2026 年 10 月 13 日
- **涵蓋範圍**：AI 通識、機器學習、深度學習、大型語言模型、生成式 AI 應用、AI 代理與 MCP、電腦視覺與多模態、強化學習、MLOps、AI 安全與倫理、中文原生資源、AI 認證
- **翻譯原則**：課程名稱以「中文譯名／英文原名」並列；除官方已有中文名稱者外，中文譯名為本倉庫意譯，**搜尋課程時請使用英文原名**

## 2026 年重點觀察（摘自分析報告）

1. **AI 代理是最熱門主題**：吳恩達、Hugging Face、微軟、Google × Kaggle、柏克萊、Anthropic、OpenAI 都推出代理課程。
2. **MCP 成為新必修**：Hugging Face、微軟、Anthropic、DeepLearning.AI 都有專門課程。
3. **模型廠商學院崛起**：Anthropic Academy、OpenAI Academy、Google Skills、NVIDIA DLI 提供大量免費課程。
4. **免費模式收緊**：Coursera 自 2025 年中起以「預覽」取代免費旁聽；DeepLearning.AI 推出 Pro 訂閱。但 GitHub 開源課綱、Hugging Face 與大學公開課仍完全免費。
5. **認證大改版**：微軟 AI-900／AI-102 退役並由 AI-901／AI-103 取代；AWS 新增生成式 AI 開發者專業認證。

完整內容請見 [分析報告](docs/analysis.md)。

## 圖例說明

**程度**

| 標示 | 意義 |
|---|---|
| ⭐ 入門 | 不需或只需少量先備知識 |
| ⭐⭐ 中級 | 需要 Python 程式能力與基礎概念 |

**費用**

| 標示 | 意義 |
|---|---|
| 免費 | 內容完全免費（可能需要註冊帳號） |
| 免費（含證書） | 內容與證書皆免費 |
| 部分免費 | 僅部分內容免費，例如 Coursera 僅首個模組可免費預覽；完整內容或證書需付費 |
